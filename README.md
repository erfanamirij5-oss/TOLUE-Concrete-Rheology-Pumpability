# TOLUE Concrete Rheology & Pumpability

**نرم‌افزار مهندسی رئولوژی و پمپ‌پذیری بتن طلوع**

این مخزن برای توسعه یک پلتفرم تجاری، فارسی و مهندسی برای تحلیل رئولوژی، پمپ‌پذیری و شبیه‌سازی مسیر پمپاژ بتن ایجاد شده است.

## اصول غیرقابل‌مذاکره

- رابط کاربری فارسی، RTL و مبتنی بر خانواده فونت Vazir
- معماری تجاری Desktop و همگرا با TOLUE Concrete Compaction
- Engineering Core مستقل، تست‌پذیر و Versioned
- هیچ خروجی عددی بدون Method، Reference، Applicability، Assumptions و Validation Status پذیرفته نیست
- تفکیک صریح Standard Requirement / Physical Model / Empirical Model / TOLUE Engineering Index / AI Prediction
- پشتیبانی از چند طرح اختلاط و Compare Mode
- کتابخانه داخلی مصالح، طرح‌ها، دانه‌بندی‌ها، خطوط پمپاژ، مدل‌ها و استانداردها
- خروجی گزارش مهندسی PDF/HTML و Render شبیه‌سازی
- 3D فقط نمایش نتایج مهندسی معتبر است؛ Animation نباید به‌عنوان شبیه‌سازی فیزیکی معرفی شود

## Scientific Foundation

شروع پروژه بر پایه Scientific Reference Matrix و Engineering Traceability انجام می‌شود. اسناد مرجع پایه شامل ACI PRC-304.2-17، ACI 211.9R-18، ACI PRC-238.1-26 و ASTM C1749-25 هستند و دامنه استانداردها در مراحل بعدی تکمیل و Versioned خواهد شد.
