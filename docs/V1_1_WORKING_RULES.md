# v1.1 Working Rules

Keep development fast and practical.

- Work only on `v1.1/ux-ui-professionalization` or short-lived branches derived from it.
- Do not rewrite the Engineering Core for UX work.
- Existing calculations remain the reference unless a separately demonstrated defect is found.
- Use the existing automated suite as the primary regression net.
- Require Windows packaging checks only when packaging/runtime behavior is touched.
- Keep pull requests small enough to diagnose failures quickly, but do not create process-only gates.
- Prefer visible product improvements over release bureaucracy during v1.1 development.
